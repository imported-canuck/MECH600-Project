# MECH600-Project
Airfoil CFD Project

analysis - Turns simulation results into tables and plots we can compare with the reference data.
foam - Sets up the OpenFOAM cases, including boundary conditions and solver settings.
mesh - Builds the meshes around the NACA 0012 airfoil.
slurm - Contains the script we use to submit jobs on the cluster.
studies - Holds the case settings and reference data for the high-Re and low-Re runs in separate folders.
